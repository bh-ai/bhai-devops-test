## Setup

```bash
pip install -r requirements.txt
```

1. Edit `connections.yml` — confirm `bootstrap_servers`, `bucket`, `region_name`, and other identity fields.
2. Export secret env vars referenced in `connections.yml` (never commit secrets):

```bash
export MIGRATE_POSTGRES_PASSWORD=...
export MIGRATE_POSTGRES_USERNAME=...
```

3. If Kafka uses SSL, place the truststore file at the path in `ssl_truststore_location` (or update that path) and set `ssl_truststore_password_env`.
4. If Kafka uses client auth (`SSL_AUTH` / keystore), also set `ssl_keystore_location` plus `ssl_keystore_password_env` / `ssl_key_password_env`.
